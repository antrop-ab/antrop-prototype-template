# Exempeldata

Påhittad data för prototypen, en fil per område (till exempel `orders.ts`).

- **Alltid påhittad.** Inga riktiga kunduppgifter, personnummer eller data från kundens system.
- **Relativ till idag.** Räkna datum från `new Date()` så att prototypen ser aktuell ut.
- **Täck in lägena.** Minst ett undantagsfall: tomt, fel, försenat, många poster.

Delat tillstånd mellan sidor, sparad data och riktiga databaser: se `.claude/skills/antrop-prototyp/references/data.md`.
