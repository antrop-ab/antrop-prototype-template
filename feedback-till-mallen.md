# Feedback till mallen

Claude skriver ned allt som krånglar med mallen här medan ni jobbar: installation, skript, komponenter som beter sig oväntat och instruktioner som saknas eller är fel. Du kan också skriva själv.

**Skicka in med `npm run feedback -- --send`** (eller be Claude "skicka feedbacken"). Det skapar ett ärende i mallens repo på GitHub, så att mallen blir bättre för nästa Antropare. Du får se texten innan den skickas.

Skriv inga kunduppgifter, inget konfidentiellt om kundprojektet och inga nycklar här.
